# TRIPEER 官网内容操作

测试 ERP：`http://124.220.2.69/admin/`。
官网测试地址：`http://124.220.2.69:18081`。

## 管理员首次设置

1. 右上角租户选择 **TRIPEER**（租户编号 163）。不要再创建同名租户。
2. 打开 **网站管理（CMS）→ 站点设置**。
3. 导航模板选 **TRIPEER · 企业官网**，站点名称为 **TRIPEER 企业官网**。
4. **站点 URL** 和 **官网草稿预览地址**均填 `http://124.220.2.69:18081`，点击 **保存配置**。这两个字段已于 2026-09-14 在测试 ERP 保存并刷新确认。
5. 打开 **网站管理（CMS）→ 页面内容**。选择 **简体中文**，点击 **导入初始内容（已有内容不会覆盖）**。确认内容、准备预览并发布；再对 **English** 执行同样操作。

租户列表中的“开启”表示租户可用。官网首次启用 CMS 还需要部署配置中的 `VITE_CMS_ENABLED=true`，由开发部署流程完成，详见 [启用说明](enablement.md)。

## 日常编辑

1. 进入 **页面内容**，选择要修改的语言。
2. 修改首页首屏的标题、副标题、介绍文字或图片地址。
3. 点击 **保存草稿**。保存不会改变公开官网。
4. 点击 **准备预览**，随后点击 **打开整页预览（链接两分钟内有效）**。预览链接只供本次查看，过期后重新准备。
5. 确认后返回 ERP，点击 **发布首页首屏**，在发布确认框中确认。
6. 刷新官网查看新内容。日常内容发布不需要重新提交 Git 或部署代码。

中文和英文分别保存、分别发布。第一批接入范围仅为首页首屏文字和图片；ERP 中现有的文章、导航等菜单不代表 TRIPEER 官网已经接入对应内容。

## 运营账号

租户、角色和登录账号是不同对象。目前已提供 TRIPEER 租户及 **品牌运营**角色（`brand_operator`），角色编码不能直接用来登录。管理员在 TRIPEER 租户内创建实际运营用户并分配该角色；密码通过账号管理流程设置，不写入 Git 或 Flyway。

品牌运营用于编辑、预览、发布本租户官网内容。站点地址等首次配置由管理员维护。
