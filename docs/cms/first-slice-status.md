# 首页 CMS 第一批实现与启用说明

更新：2026-09-11。状态：首屏功能已实现并通过本地验证；未部署测试/生产服务器，未进行真实运营账号端到端验收。

## 已实现

- ERP 页面内容表、不可变发布版本表，独立 TRIPEER 租户/站点/品牌运营角色的迁移脚本。
- 首页首屏中文/英文的标题、副标题、介绍正文、背景图片地址和图片说明。
- 初始内容导入、读取草稿、保存、发布、发布历史、一次性预览凭证及短期只读预览。
- 保存版本冲突检查；数据库行锁保护并发保存；重复发布同版本不产生多份历史。
- 独立权限 `seo:page:query/update/publish/preview` 和租户/站点/语言隔离。
- ERP“网站管理（CMS）→ 页面内容”编辑页，站点设置中的独立预览地址。
- 官网首屏绑定、真实首页预览入口、退出预览和凭证清理。
- 本地 Vite 代理、服务器 Nginx 配置示例；浏览器不持有 ERP 管理员凭证。

第一版整页预览展示真实官网，但只有首屏使用 CMS 草稿；其他模块仍是现有前端内容。文章、导航和全局资源的组合草稿预览留待后续阶段。

## 测试环境启用步骤

1. 构建并部署包含本次改动的 ERP 后端和管理端，在测试数据库应用 V050。该步骤本次尚未执行；不要把只改源码当成服务器已更新。
2. 管理员切换到 TRIPEER 租户，在站点设置配置官网地址和草稿预览地址。本机联调可用实际运行的 `http://localhost:5173`，必须与打开官网使用的主机名和端口一致；不要在 localhost 与 127.0.0.1 间混用。多人预览使用可访问的测试地址。
3. 管理员在 TRIPEER 租户创建实际运营账号（建议首个账号名 `brand`），分配“品牌运营”角色。迁移不会创建登录账号，也没有密码或哈希。
4. 查看 TRIPEER 的实际 tenantId。可在后台查看，或对测试库执行只读 SQL：

   ```sql
   SELECT id, code, name FROM system_tenant
   WHERE code = 'TRIPEER' AND deleted = b'0';
   ```

5. 官网将根目录 `.env.cms.example` 复制为 `.env.local`，填写实际参数：

   ```dotenv
   VITE_CMS_ENABLED=true
   CMS_UPSTREAM=http://实际测试ERP地址:实际端口
   CMS_TENANT_ID=数据库实际分配的ID
   ```

   上面是占位说明，不能原样运行。CMS_UPSTREAM 应为 ERP API 服务根地址，不追加 /admin-api；CMS_TENANT_ID 不是账号密码。未开启 CMS 时官网继续显示现有静态内容；开启后接口失败会明确报错，不用静态标题伪装读取成功。

6. 启动官网开发服务，重新启动使环境配置生效。日常启动可用 `npm run dev`；自动化启动应作为后台进程并记录 PID、日志。需要启动 ERP 时遵守 ERP 仓库的统一生命周期脚本，不另起一套零散服务。
7. 进入 ERP 页面内容，分别为中文、英文点击“导入初始内容”。只导入缺失记录，不覆盖已有编辑；导入内容是草稿，首次发布前普通 CMS 接口返回“尚未发布”。
8. 修改标题或图片 → 保存草稿 → 准备预览 → 打开整页预览 → 返回 ERP 发布。普通官网刷新后显示发布版。再修改但不发布，确认普通页面没有变化。
9. 用实际家具运营账号和品牌运营账号交叉验证管理接口；不仅检查菜单，还要验证替换参数后后端拒绝越权。
10. 网站部署时，服务器需配置 `deploy/cms-proxy.nginx.example` 中的转发规则，替换租户占位符和 ERP 地址；Vite 开发代理不会自动进入静态网站服务器。官网构建时也必须设置 `VITE_CMS_ENABLED=true`，并提供配置校验需要的服务端代理参数。

## 当前接口清单

后台前缀：`/admin-api/seo/page`；官网前缀：`/app-api/seo/page`。

| 类型 | 已实现路径 |
| --- | --- |
| 后台 | GET /schema、GET /draft、POST /initialize |
| 后台 | PUT /draft、POST /publish、GET /history、POST /preview-ticket |
| 官网 | GET /public、POST /preview/exchange、GET /preview |

参数 pageKey 当前仅支持 home，locale 当前仅支持 zh-CN/en。站点模板必须为 TRIPEER_CORPORATE。结构定义固定为 v1，拒绝额外字段和任意脚本内容。

预览 URL 形如 `/#/cms-preview?ticket=...`；一次性链接有效期 2 分钟，会话最长 15 分钟，仅存内存。刷新已移除 ticket 的预览页需要从 ERP 重新打开。第一版预览固定语言，不提供切换为另一个未授权语言草稿的入口。

图片第一版支持现有 /assets/ 路径及不带查询参数的 HTTPS 地址；不接受临时签名地址。媒体上传与归属管理属于后续接入，当前不是图片上传器。发布历史目前可查看，恢复历史为草稿暂未实现。
