# TRIPEER 官网接入 ERP CMS：实施计划

更新日期：2026-09-11。状态：首屏代码已实现并通过本地验证，测试环境部署与账号验收待完成。见 [首批状态与启用说明](first-slice-status.md)；以下阶段清单仍以完整环境验收为完成条件。

## 要完成的结果

运营人员使用 ERP 的品牌运营账号，编辑本官网的文字、图片、导航和文章。保存后可打开真实官网预览草稿；发布后，普通访客刷新官网看到正式内容。家具 B2B、B2C 和 TRIPEER 的内容按租户隔离。

第一次验收只做一条完整链路：**修改首页标题和背景图片 → 保存草稿 → 打开整页预览 → 发布 → 刷新普通官网验证**。通过后按相同方式接入其他内容。

规划后的首批开发已修改官网和 ERP 源码并新增迁移脚本；尚未修改服务器数据库、创建实际账号或推送 GitHub。

## 已核对的项目现状

| 项目 | 当前情况 | 实施影响 |

官网核对基线为 `6de5b00`。ERP 参考本地 `D:\code\.worktrees\main-v026-fix` 下的模块源码；开始开发前重新核对 main、迁移编号及服务版本。本计划不代表测试服务器已部署这些代码，也不代表已完成多账号实测。

## 固定设计

- 租户标识拟为 `TRIPEER`，实际 tenantId 由数据库分配；该租户下使用独立站点，初始 siteId 规划为 `1`，初始化时检查冲突。
- 官网模板拟为 `TRIPEER_CORPORATE`；模板不是 ERP 的 B2B/B2C businessMode，不能直接把模板名填进业务模式字段。
- 角色拟为“品牌运营” `brand_operator`。首次账号拟为 `brand`，由管理员在 ERP 创建并分配角色；实际多人使用时每人一个账号。
- 复用 ERP 登录和租户鉴权。角色权限采用明确清单，不使用 `seo:*`，不自动赋予租户管理、用户管理、跨租户访问、任意 JavaScript 发布权限。
- 内容、数据结构、菜单、角色及站点模板可纳入代码管理；账号密码、哈希、预览凭证、私钥不写入迁移或示例文件。
- 先支持固定页面模块的内容编辑。布局、组件类型、图标和动画由代码管理；不建设任意拖拽页面搭建器。
- 页面草稿和发布快照分开。一次发布只发布所选资源与语言，不默默发布其他页面、导航或文章草稿。
- 预览显示真实官网组件。默认“当前页面草稿 + 其他资源的已发布版本”；组合预览时必须明确选择资源并检查各资源的预览权限。
- 首页新闻使用已有 Blog 的文章引用或筛选结果，不维护另一套重复文章正文。
- 公共联系方式、品牌信息和页脚使用共享内容资源 `site-global`。页脚导航继续复用导航数据，不在多个地方重复存储。

## 实施顺序

### 第 0 步：落实清单（本次已完成）

- [x] 核对官网组件、路由及主要内容来源。
- [x] 区分 ERP 现有接口与拟新增接口。
- [x] 编写 [内容对应表](content-map.md)。
- [x] 编写 [接口与函数约定](api-contract.md)。
- [x] 确定分阶段实施和验收方式。

### 第 1 步：确认内容结构、站点和权限基础

工作：

1. 在两个仓库各自的任务分支上开发，先检查现有改动；ERP 从最新本地 main 开始，不复用长期任务分支。
2. 将页面目录、模块 key、字段类型和版本固化为一份机器可读的模板定义。ERP 为运行时权威来源，官网消费版本化契约；两端不能独立修改同名字段的含义。
3. 增加页面/发布快照表，配置菜单、角色、TRIPEER 站点模板和权限清单。Flyway 编号以开发时的最新编号为准。
4. 按自然键查找或创建租户、站点、角色，避免重复执行产生多份记录。不能直接复用会自动创建租户管理员账号的流程来创建品牌运营账号。
5. 管理员创建或绑定实际品牌运营账号。联调用账号与生产账号分开管理。

验收：同一租户 + 站点 + 页面 + 语言只存在一条主记录；品牌运营能看到本官网管理菜单；家具账号不能读取或修改本官网的管理数据。

### 第 2 步：完成首页首屏的端到端联调

工作：

1. 增加首页首屏的 schema，先开放标题、副标题、正文、背景图片及替代文本。
2. 从官网当前中英文内容提取初始值；仅初始化不存在的记录，禁止覆盖运营后续编辑。
3. 增加读取草稿、保存草稿、发布、读取正式页面接口和版本冲突处理。
4. ERP 增加页面选择、语言选择、字段编辑和保存/发布功能。
5. 官网增加 CMS API 层和 `usePageContent('home')`，绑定首屏内容，保留已有样式。
6. 配置本地 Vite 代理到测试 ERP；浏览器中不保存 ERP 管理员凭证。
7. 完成第 3 步的基本预览后，才将本步骤标记为验收完成。

验收：中英文分别修改；草稿不影响访客；发布后刷新显示新版本；旧版本保存不能覆盖新版本；图片和多行标题正常展示。

### 第 3 步：打通真实整页预览

工作：

1. ERP 保存草稿后获取最新版本，再生成一次性 ticket；后端创建内容快照和资源版本清单。
2. 站点配置增加独立 `previewBaseUrl`，测试时指向实际运行的本地官网。验证允许的地址和站点归属，不接受任意跳转目标。
3. 官网新增兼容 Hash 路由的预览入口，兑换 ticket，清除地址中的凭证，将短期只读会话仅保存在内存中。
4. `AppShell.vue` 按预览返回的 pageKey 选择实际组件；页面、导航、全局信息和相关文章统一从预览上下文读取。
5. 会话绑定租户、站点、语言、页面及获准资源版本。未知资源不读取草稿；无权访问、凭证过期或重复兑换必须失败。
6. 首次只预览当前页面草稿，其他资源使用固定的正式快照；后续增加导航/文章草稿组合预览，不能把导航凭证直接当作所有内容的通行证。

验收：预览是完整官网；普通访客仍看到正式版；预览期间再次编辑不会静默改变既有预览快照；过期后提示重新从 ERP 打开；没有双重页头、页脚或默认落入公司介绍组件的问题。

本地预览只供能访问该本地服务的电脑使用。多人预览时再配置可访问的测试部署地址。发布无需官网反向连接 ERP 管理后台。

### 第 4 步：扩展首页、公共信息、导航和新闻

工作：

1. 按对应表绑定首页全部可见模块、站点共享信息、页脚联系方式和品牌图片。
2. 导航模板支持本站页面 key；补充语言编辑；保留桌面/手机交互。
3. Blog 增加或核对分类字段与公开列表筛选，支持 company、events、industry、responsibility。
4. 新增文章详情路由和渲染组件；同时处理 AppShell 分发、404、下线文章和分页。
5. 首页新闻、新闻列表和文章详情统一读取 Blog；已有示例卡片没有完整正文，先作为待补充草稿导入，不能编造正文自动发布。
6. 更新站内搜索，至少支持已发布文章的服务端搜索，并保留稳定页面目录；不得索引草稿。

验收：修改菜单名称后官网更新；两种语言互不覆盖；首页卡片可进入对应文章；文章下线后从列表和搜索消失；本站文章不会出现在家具站点。

### 第 5 步：覆盖其他页面及 SEO

工作：

1. 接入公司概况、历程、市场、文化、业务、核心能力及联系页的展示内容。
2. 明确 culture 与 mission 的共享正文关系；所有数组项有稳定 ID，不能用标题或数组下标作为永久身份。
3. 页面 SEO 与现有 SEO 模块建立唯一映射，避免页面 JSON 和 SEO 表都维护一份标题。
4. 统一 App.vue 与 AppShell.vue 的 meta 更新逻辑，避免旧路由文案覆盖 CMS SEO。
5. 公共字段复用 `site-global`；尚未确认的邮箱、电话、备案、社交账号保持未启用，不捏造真实值。

验收：对应表中的页面逐个有数据来源；路由切换/语言切换不会显示上个页面的数据；SEO 随当前页面更新；手机和桌面保留原来的内容结构和交互。

### 第 6 步：测试部署与交付

工作：

1. 核对测试 ERP 的实际代码版本、数据库迁移及接口，再部署匹配版本。仅使用用户指定测试环境，生产部署另行处理。
2. 将本地代理规则转换为服务器代理规则：仅转发所需公开/预览接口，固定本站租户上下文，不开放后台写接口。
3. 配置站点正式地址和测试预览地址；如迁移 History 路由，同步配置服务器回退及旧链接兼容，单独验证。
4. 对管理操作、公开接口、草稿预览分别验证缓存策略。第一版内容接口禁用缓存，后续才增加带明确失效策略的缓存。
5. 记录账号权限、备份恢复和发布操作说明。回退通过历史快照恢复为草稿、审核后再发布；不要删除线上版本。
6. 按仓库要求完成必要验证和本地合并；只有获得推送授权才上传 GitHub。

验收：完成下表全部必测项，记录代码版本、迁移版本及测试结果。

## 必测清单

| 场景 | 预期 |
| --- | --- |
| 修改但不发布 | 仅草稿变化，普通官网保持正式内容 |
| 预览 | 页面、图片、页头和页脚使用真实官网组件 |
| 发布指定草稿版本 | 普通访问刷新看到该版本，其他草稿不被发布 |
| 两个编辑者基于同一版本保存 | 后提交者得到冲突，不能覆盖前者 |
| 家具账号替换 pageId/siteId 等参数 | 后端拒绝跨租户管理操作，不能只依赖菜单隐藏 |
| 有编辑权限但无发布权限 | 可保存，不能发布或越权生成预览 |
| 无凭证、重复 ticket、过期会话 | 不能取得草稿，响应不进入共享缓存 |
| 中英文切换、快速切换页面 | 正确匹配页面/语言，过期请求结果不覆盖当前页面 |
| ERP 不可用 | 显示可重试错误或同站点同语言的已发布缓存，绝不回退草稿或假装保存成功 |
| 恶意 HTML/链接/图片引用 | 按允许字段、富文本规则和 URL 协议校验；普通文字不作为 HTML 执行 |
| 重跑内容初始化 | 不产生重复记录，不覆盖运营编辑 |
| 新站点部署 | 静态图片路径或媒体域名可访问；没有 localhost 生产地址或浏览器端秘密 |

## 不影响先行开发的待定信息

正式域名、最终联系资料、真实运营人员账号、共享预览部署地址可以在相应阶段补齐。开始首页本地联调不依赖正式域名。

本轮不包含商务询盘入库、求职简历处理、自由拖拽建站、自动发布到生产。这些功能分别涉及业务流程或独立部署安排。
